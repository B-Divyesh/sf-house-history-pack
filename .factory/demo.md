# Demo sandbox

Open [the demo](/demo) or choose **Try it with sample data** on the first
screen. It loads Juniper House: two systems, two history records, two upcoming
tasks, and a service receipt. The pack builder can immediately create the
sample PDF, ZIP, and encrypted backup.

Demo data lives only in IndexedDB database `demo:house-history-pack`; real
records use `house-history-pack`. The persistent banner provides **Reset demo**
to restore the shipped sample and **Start for real** to delete the demo
database before opening the empty real workspace.
